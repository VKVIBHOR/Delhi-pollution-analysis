# 🌫️ Delhi Pollution Analysis & Forecasting

An interactive web app analyzing Delhi's air quality using ML-powered AQI forecasting. Features pollution simulation, policy impact scenarios, city rankings, and health insights.

## Features
- 🔮 **ML-Powered AQI Forecasting** - Predict next-day air quality using Random Forest
- 📊 **Policy Simulation** - Compare pollution control strategies
- 📈 **Rankings & Insights** - Effectiveness analysis of various policies
- 🌐 **Interactive Dashboard** - Modern web interface for visualization

## Installation

```bash
# Clone the repository
git clone [https://github.com/VKVIBHOR/Delhi-pollution-analysis.git](https://github.com/VKVIBHOR/Delhi-pollution-analysis.git)
cd Delhi-pollution-analysis

# Create virtual environment
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
